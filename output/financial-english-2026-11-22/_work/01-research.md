# 研究摘要：金融英文的詞源

日期：2026-11-22｜slug：`financial-english`｜Agent：topic-analyzer

範圍：主題型題目，挑 10 個字，條件是「詞源有文獻、有故事、讀者天天看得到」。入選：fee, pecuniary, capital, cattle, money, bank, bankrupt, credit, debt, mortgage, finance, salary。

## 1. 詞源事實

| # | 事實 | 可信度 | 來源 |
|---|---|---|---|
| F1 | fee 來自古英語 *feoh*：先指牲畜、牛，再指動產、財富，最後指錢 | ✅ | [E1] |
| F2 | *feoh* 的同源字：德語 *Vieh*（牲畜）、哥德語 *faihu*（錢、財富）；PIE 詞根 \*peku-「牲畜」，也產生拉丁語 *pecu*（牲畜）與 *pecunia*（錢、財產） | ✅ | [E1] |
| F3 | fee 的另一來源是封建制度的 *fief*（封地）；約 1300 年起指封地，後來指職位報酬，再變成「費用」 | ✅ | [E1] |
| F4 | 英語 pecuniary（金錢上的）、impecunious（身無分文的）來自拉丁 *pecunia* | ✅ | [E1] 推得；一般字典 |
| F5 | capital（資本）來自中世紀拉丁 *capitale*「財產、資產」，源自 *caput*「頭」；1610 年代進入英語指「個人財富」，1640 年代指「投入事業的資金」 | ✅ | [E2] |
| F6 | cattle 來自同一個 *capitale*：13 世紀中期指任何財產（含錢、土地），14 世紀初縮小為「可移動財產、牲畜」，16 世紀後期才專指牛 | ✅ | [E3] |
| F7 | chattel（動產）是 cattle 的雙式詞（doublet），同樣來自 *capitale* | ✅ | [E3] |
| F8 | money 來自拉丁 *moneta*「鑄幣廠、鑄好的錢」。Moneta 是女神 Juno 的稱號，羅馬人在她位於卡比托利歐山的神廟附近鑄幣 | ✅ | [E4] |
| F9 | Moneta 傳統上被連到 *monere*「警告、勸告」（「提出警告的女神」），但 Etymonline 說這個詞源「難以確定」 | ⚠️ | [E4] |
| F10 | bank（銀行）來自古義大利語 *banca*「桌子、錢商的檯面」，源自日耳曼語的「長凳」；15 世紀後期進入英語，1620 年代才有「收受與放貸金錢的機構」之意 | ✅ | [E5] |
| F11 | bank（銀行）、bench（長凳）、bank（河岸）三者是同一個日耳曼詞根的平行後代 | ✅ | [E5] |
| F12 | bankrupt 來自義大利語 *banca rotta*「破掉的長凳」，1560 年代進入英語；後半部被英語改成拉丁 *rupta*（*rumpere* 打破） | ✅ | [E6] |
| F13 | 「破產的錢商會被當眾砸爛長凳」這個故事，Etymonline 認為「大概只是比喻」，不是有紀錄的習俗 | ✅（作為「此說存疑」） | [E6] |
| F14 | credit 於 1540 年代進入英語，原意「信念、信任」；經法語、義大利語，來自拉丁 *creditum*「借出之物、託付之物」，*credere*「相信、託付」 | ✅ | [E7] |
| F15 | *credere* 來自 PIE \*kerd-dhe-，字面是「把心放上去」；\*kerd- = 心。同家族：creed、credo | ✅ | [E7] |
| F16 | debt：中古英語拼作 *dette*（來自古法語），源頭是拉丁 *debitum*（*debere* 欠） | ✅ | [E8][M1] |
| F17 | debt 的 b 是懂拉丁文的學者為了對應 *debitum* 而加進拼字的，從來沒有人發音 | ✅ | [M1][W1] |
| F18 | 加 b 的確切年代：Etymonline 寫「約 1400 年後」，World Wide Words 寫 16 世紀 | ⚠️ 來源不一 | [E8][W1] |
| F19 | mortgage 來自古法語 *mort gaige*「死亡的抵押」，14 世紀後期進入英語 | ✅ | [E9] |
| F20 | 17 世紀法學家 Sir Edward Coke 的解釋：借款人到期不還，土地永遠歸對方，抵押對他「死了」；還了錢，抵押對放款人「死了」 | ✅ | [E9] |
| F21 | finance 約 1400 年進入英語，原意「結束、了結、清償」；古法語 *finer*「結束、了結債務」，*fin*「終點」，拉丁 *finis*。「管理金錢」的意思 1770 年才出現 | ✅ | [E10] |
| F22 | fine（罰款）也來自 *finis*：付一筆錢讓事情「了結」 | ✅ | [E10] |
| F23 | salary 來自拉丁 *salarium*（津貼、薪俸），源自形容詞 *salarius*「與鹽有關的」，*sal* = 鹽。字和鹽有關是真的 | ✅ | [E11] |
| F24 | 「羅馬士兵領鹽當薪水」沒有任何古代文獻支持；連「買鹽的津貼」也只是近代的推測 | ✅（作為「此說無據」） | [E11][G1] |
| F25 | 漢字「貝」是海貝的象形；古時以貝殼為貨幣，所以從貝的字多與錢財有關：財、貨、買、賣、貴、貸、資、賠、賺 | ✅ | [Z1][Z2] |
| F26 | 《說文解字》：「古者貨貝而寶龜，周而有泉，至秦廢貝行錢。」（公有領域） | ✅ | [Z2] |
| F27 | 「本」：《說文》「木下曰本」，本義是樹根；「本錢」「資本」用的是同一個「根本」的意象 | ✅ | 《說文解字》 |
| F28 | 「信」：《說文》「信，誠也，从人从言」 | ✅ | 《說文解字》 |

## 2. 演變路徑（主線）

```
牲畜即財富：PIE *peku- → 古英語 feoh → fee
                       → 拉丁 pecu → pecunia → pecuniary
            拉丁 caput（頭）→ capitale（財產）→ capital／cattle／chattel
神廟鑄幣：  Juno Moneta → moneta → 古法語 monoie → money
一張長凳：  日耳曼 *bank- → 義大利 banca → bank；banca rotta → bankrupt
一個承諾：  credere（把心放上去）→ credit
            debere（欠）→ debitum → dette → debt（學者加 b）
            mort gaige（死亡抵押）→ mortgage
一個結束：  finis → fin → finer → finance；fine（罰款）
```

## 3. 同源字家族

| 家族 | 成員 |
|---|---|
| \*peku-（牲畜） | fee, pecuniary, impecunious |
| *caput*（頭） | capital, cattle, chattel |
| *credere*（相信） | credit, creditor, creed, credo |
| *finis*（結束） | finance, fine（罰款）, final, finish |
| *banca*（長凳） | bank, bankrupt；遠親 bench |

### 陷阱：看起來是、其實不是
- **salary ≠ 用鹽發薪**：字跟鹽有關（F23），故事沒證據（F24）。
- **bankrupt ≠ 有砸凳子的習俗**：字面是「破長凳」（F12），砸凳子的故事存疑（F13）。

## 4. 常見誤解

1. 羅馬士兵領鹽當薪水（F24）
2. 破產的錢商真的被砸凳子（F13）
3. debt 的 b 以前有發音（F17）
4. bank 和河岸的 bank 一個來自另一個——其實是平行的兄弟（F11）

## 5. 教學切入點

- **反直覺鉤子**：你付的每一筆 fee，祖先是一頭牛（F1）。
- **一條歷史線**：錢的形態從「數得出來的牲畜」→「神廟鑄的金屬」→「錢商的桌子」→「只能相信的承諾」。
- **中英對照**：英文的錢來自牛，中文的錢來自貝殼（F25–F26）；capital 是「頭」，資本的「本」是「根」（F27）；credit 是「把心放上去」，「信」是「人言」（F15、F28）。
- **投資讀者的連結**：現代金融的核心是 credit——一個字就說明了信用為什麼會崩潰。

## 6. 推薦角度

- **主角度：「從牛到信用」**（From Cattle to Credit）
  核心：金融英文按順序排好，就是一部錢的歷史——從牲畜、神廟、桌子，到承諾。
  理由：有歷史縱軸（大綱好排）、兩個迷思可以拆（教學張力）、中文「貝」提供完美對照（雙語定位）、對投資讀者有現實意義（credit 就是信任）。
- **備選角度：「金融英文迷思破解」**（salary、bankrupt、debt）——適合單獨做 Shorts。

## 7. 給下一關的提醒

- F9（Moneta 與 monere）只能寫成「傳統說法，詞源不確定」。
- F13、F24 必須以「存疑／無據」語氣出現，正文裡不能把故事講成事實再補一句「但其實…」——開頭就說清楚。
- F18 不寫具體年代，只寫「後來的學者」。
- F20 Coke 的解釋屬於 17 世紀法律文獻，可改寫轉述。
- 「credit ↔ 信」「capital ↔ 本」是**意象平行**，不是同源；正文要說清楚是「巧合的相似」。
