# 研究摘要：metaphor 的詞源

日期：2026-11-22｜slug：`metaphor`｜Agent：topic-analyzer

## 1. 詞源事實

| # | 事實 | 可信度 | 來源 |
|---|---|---|---|
| F1 | metaphor 於 15 世紀後期進入英語，經古法語 *metafore*（13 世紀）／拉丁語 *metaphora* | ✅ | [E1] |
| F2 | 希臘語 μεταφορά (metaphorá) 意為「轉移、搬運過去」，特指把一個字的意義轉到另一個字上 | ✅ | [E1] |
| F3 | 構詞：`meta-`（跨越、轉換）＋ `pherein`（攜帶、承載）；動詞 μεταφέρειν 意為「搬移、改變、用一個字表達特殊意思」 | ✅ | [E1] |
| F4 | PIE 詞根 \*bher- (1)「攜帶」，也有「生育」之意 | ✅ | [E1][E2] |
| F5 | 同一詞根的拉丁路線 *ferre*：transfer, refer, differ, offer, prefer, suffer, confer, infer, fertile | ✅ | [E2] |
| F6 | 同一詞根的希臘路線 *pherein*：euphoria, phosphorus, amphora, periphery, semaphore, pheromone, Christopher | ✅ | [E2] |
| F7 | 同一詞根的英語本土路線（日耳曼）：bear, birth, burden, bring | ✅ | [E2] |
| F8 | translate 來自拉丁 *translatus*，是 *transferre*（trans- 跨越 ＋ ferre 攜帶）的過去分詞；*lātus* 是 *ferre* 的異幹（suppletive）過去分詞 | ✅ | [E3] |
| F9 | Quintilian（約西元 95 年，《雄辯術原理》8.6）稱 metaphor 是「我們拉丁語 *translatio* 的希臘說法」 | ✅ | [P1] |
| F10 | Quintilian 區分：說某人「像獅子一樣」做事是比較（comparison／simile）；說「他是一頭獅子」才是 metaphor | ✅ | [P1] |
| F11 | Quintilian：metaphor 是極自然的說法，常被人無意識地使用，連沒受過教育的人也用 | ✅ | [P1] |
| F12 | Aristotle《詩學》：最了不起的是掌握 metaphor；這無法從別人那裡學來，是天才的標誌，因為好的 metaphor 需要看出相似性的眼光（Butcher 1895 譯本，公有領域） | ✅ | [P2] |
| F13 | Aristotle 定義：metaphor 是把屬於另一事物的名稱給予某物（Bywater 1909 譯本，公有領域） | ✅ | [P3] |
| F14 | 現代希臘語 μεταφορά 仍是「運輸、搬運」的日常用字；複數 μεταφορές = 運輸（業） | ✅ | [W1][W2] |
| F15 | 現代希臘語「搬家公司」= μεταφορική εταιρεία（metaforikí etairía），字面上就是「metaphor-ic 公司」 | ✅ | [W3] |
| F16 | Michel de Certeau（《日常生活實踐》，1980）寫道：在現代雅典，大眾運輸工具叫 metaphorai，搭公車上班就是搭一個「metaphor」 | ✅（作為「他寫了什麼」） | [C1][C2] |
| F17 | 希臘街頭幾乎每輛搬家卡車都印著 ΜΕΤΑΦΟΡΕΣ | ⚠️ | 僅非權威來源 [X1][X2] |
| F18 | `meta-` 因 metaphysics 被誤讀為「更高、超越」，才產生 metalanguage（1936）等現代用法；metaphor 裡的 meta- 是「跨越、轉換」 | ✅ | [E1] |
| F19 | ferry 不屬於 \*bher- 家族：古英語 *ferian*，原始日耳曼語 \*farjan，PIE \*per- (2)「引導、越過」 | ✅ | [E4][E2] |
| F20 | Lakoff & Johnson《Metaphors We Live By》（1980）提出概念隱喻（conceptual metaphor）：日常思考本身大量以隱喻組織；代表例 ARGUMENT IS WAR（辯論是戰爭） | ✅ | [L1][L2] |
| F21 | 中文同樣有「辯論是戰爭」：唇槍舌劍、論戰、筆戰、攻防、駁倒 | ✅（常用語） | 一般語文知識 |
| F22 | 中英都有「死隱喻」（dead metaphor）：the foot of a mountain／山腳、the leg of a table／桌腳、bottleneck／瓶頸 | ✅（常用語） | 一般語文知識 |

## 2. 演變路徑

```
PIE *bher- 「攜帶」
 ├─ 希臘 pherein ── meta- + pherein → metapherein（搬過去）→ metaphora（轉移）
 │                                                         ├─ 拉丁 metaphora（借用）
 │                                                         │    └─ 古法語 metafore（13 世紀）→ 英語 metaphor（15 世紀後期）
 │                                                         └─ 現代希臘語 μεταφορά（運輸／隱喻，兩義並存）
 ├─ 拉丁 ferre ── trans- + ferre → transferre → 過去分詞 translatus → translate
 │                                └─ translatio：Quintilian 用來翻譯 metaphora 的拉丁字
 └─ 日耳曼 → 古英語 beran → bear, birth, burden
```

## 3. 同源字家族

### 希臘路線（-pher-, -phor-）
| 字 | 構詞 | 字面 |
|---|---|---|
| euphoria | eu-（好）＋ pherein | 「承受得好」→ 狂喜 |
| phosphorus | phos（光）＋ -phoros | 「帶來光的」 |
| amphora | amphi-（兩邊）＋ -phoros | 「兩邊都能提」的雙耳瓶 |
| periphery | peri-（周圍）＋ pherein | 「繞著搬一圈」→ 周邊 |
| semaphore | sema（信號）＋ -phoros | 「攜帶信號的」→ 旗語、號誌 |
| Christopher | Christos ＋ -phoros | 「背負基督的人」 |

### 拉丁路線（-fer）
transfer（搬過去）、refer（帶回去）、offer（帶到面前）、prefer（帶到前面＝優先）、differ（分開帶）、suffer（在底下承受）、fertile（能結果的）

### 本土路線
bear（承受；生）、birth（出生）、burden（負擔）

### 陷阱：看起來是、其實不是
- **ferry**：長得像 *ferre*，意思也是「載運」，但來自另一個 PIE 詞根 \*per- (2)。（F19）

## 4. 常見誤解

1. **「meta = 更高層次」**：現代網路用語 meta（自我指涉、更上一層）來自對 metaphysics 的誤讀；metaphor 的 meta- 是「跨越、轉換」。（F18）
2. **「metaphor 只是文學修辭」**：古羅馬的 Quintilian 已指出一般人天天無意識地用；Lakoff & Johnson 進一步主張它是思考的基本方式。（F11, F20）
3. **metaphor vs simile 分不清**：有 like/as 是 simile（明喻）；直接說 A 是 B 是 metaphor（隱喻／暗喻）。Quintilian 的獅子例最清楚。（F10）
4. **以為 translate 和 metaphor 無關**：兩者是同一個意象的希臘版與拉丁版。（F8, F9）

## 5. 教學切入點

- **畫面鉤子**：在雅典，搬家公司叫「metaphoric company」（F15）；de Certeau 說搭公車上班就是搭一個 metaphor（F16）。
- **一個字解鎖一串字**：認得 -pher-／-fer 就能拆 euphoria、semaphore、transfer、suffer。
- **雙胞胎發現**：metaphor（希臘）＝ transfer／translate（拉丁），字面都是「搬過去」。對雙語學習者特別有感：翻譯本身就是一種 metaphor。
- **中英對照**：中文也有「唇槍舌劍」「筆戰」（ARGUMENT IS WAR）、「山腳」「瓶頸」（dead metaphor）——隱喻不是英文特產，是人類思考的方式。

## 6. 推薦角度

- **主角度：「Metaphor 是一輛搬家車」**（The Moving Truck of Meaning）
  核心：metaphor 字面就是「把意思搬過去」；這一個意象串起希臘搬家公司、拉丁 translate、-fer／-pher 字族、以及我們每天用的隱喻。
  理由：有具體畫面（適合縮圖與鉤子）、一次教一整個字族（教學價值高）、自然帶出中英對照（符合雙語定位）。
- **備選角度：「從戰場隱喻到日常語言」**（ARGUMENT IS WAR）
  可作為主文其中一節；也適合單獨拍一支短影音。

## 7. 給下一關的提醒

- F17（搬家卡車印字）只有非權威來源：**不可寫成「每輛卡車都印著」**。改用已核實的 F15（搬家公司＝μεταφορική εταιρεία）。圖片可畫搬家車，但不在正文宣稱街景事實。
- F16 是 de Certeau 的觀察，寫成「de Certeau 寫道…」並改寫轉述，不直接引用（現代著作）。
- F20 Lakoff & Johnson 是現代著作：改寫轉述，例句用通用英文慣用語自行撰寫。
- F12、F13 可直接短引（Butcher 1895／Bywater 1909 公有領域）。F9–F11 用 Butler 1920 譯本，可短引。
